# Contributing to LUMOS

Preserve the unified shared-engine/domain-adapter architecture, scientific limitations and intended-use guidance, static GitHub Pages compatibility, deterministic evidence, accessibility controls, and browser-local credential boundary. New operational fields must retain provenance and must not be presented as authenticated. Run `npm run verify` before proposing release changes.

---

1. Keep the domain-independent Bayesian and social decision engine separate from domain adapters and visualization code.
2. Add tests for every scientific transformation, constraint, data-schema change, and export contract.
3. Label every input as observed, modeled, derived, or proxied.
4. Never convert an optional-source failure into silent synthetic data.
5. Do not claim deployment feasibility from a mapped location alone.
6. Preserve deterministic seeds and report benchmark rules fairly.
7. Run `npm test` and `npm run check:live` before proposing a release.
